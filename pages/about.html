About UseArazzo

Building deterministic API workflow tooling, with over 15 years of combined industry experience.

Our Mission

A single API call is a solved problem. Everything above it is not: the order you call the endpoints in, what you carry between them, and how you know you are done. Today that logic mostly lives as improvisation, in an agent's runtime, in a hand-written script, or in a developer's head.

We believe multi-step API workflows deserve the same rigor OpenAPI brought to single endpoints: described once, in a standard, and executed the same way every time. That's what Arazzo is for, and UseArazzo exists to validate and run it: deterministically, on your machine, in CI, or through an agent.

Swagger open-source projects

Before UseArazzo we were core contributors to the Swagger open-source projects: Swagger UI, Swagger JS, and Swagger Editor on the JavaScript side, Swagger Core, Swagger Codegen, and Swagger Parser on the Java side. Each link opens our commit history on that project.

Built on SpecLynx

UseArazzo is built end to end on SpecLynx, our own API tooling foundation: the semantic parsing core, reference resolution, and standards discipline behind years of Swagger/OpenAPI tooling. The toolkit sits on that foundation, which is why it handles malformed documents, external references, and specification edge cases from day one rather than learning them the hard way.
