Package reference

A published package gets its API reference here. Until a package publishes, its README in the arazzo-toolkit monorepo is the reference.

Published on npm as an alpha

@usearazzo/parser

Parses Arazzo and OpenAPI documents into an ApiDOM data model, and parses runtime expressions and criterion conditions into syntax trees.

API reference
