UseArazzo CLI

In development

One command-line interface across the toolchain: validate and run Arazzo workflows on your machine and in CI.

@usearazzo/cli is meant to be the front door to the toolkit: the same validation and execution engines the libraries expose, wrapped in a single binary for your terminal or CI/CD pipeline. It is the package the rest of this page describes, and it has not shipped yet.

Not yet published. There is no @usearazzo/cli package on npm today. The commands below describe the intended interface, built from the Validator and Runner libraries, which are unpublished and under heavy development themselves. Treat exact flag names as subject to change. Follow Discussions to hear when it ships.

The two engines it will wrap are being built in the open, and are not published either:

Planned Commands

Two commands, mapped directly onto the two things the toolkit already does as libraries.

validate

Validate an Arazzo document, either a local file or a remote URL, against the specification. Wraps @usearazzo/validator's validateURI, which already runs semantic validation, reference checks, and linting, and returns LSP-compatible diagnostics. 

usearazzo validate <uri>

What it would report today, via the library:

  • ✓ Semantic validation against the Arazzo 1.0.0 / 1.0.1 specification
  • ✓ Reference resolution for local $ref pointers in inputs
  • ✓ Semantic linting, with opt-in JSON Schema (AJV) validation

run

Run an Arazzo workflow against live APIs and print the step-by-step trace. Wraps @usearazzo/runner's WorkflowExecutor, which already resolves inputs, evaluates criteria, and follows goto / retry / end actions. 

usearazzo run <uri> <workflowId> --input key=value

What it would report today, via the library:

  • ✓ Final status: completed, ended, or failed
  • ✓ Per-step trace: success, action taken, attempt count, duration
  • ✓ The workflow's resolved outputs

Note: the Runner itself is pre-1.0 and privately versioned within the monorepo. See its own page for what's implemented today versus what's still in progress.

Frequently Asked Questions

Can I install UseArazzo CLI today?

No. There is no @usearazzo/cli package on npm, and neither the Validator nor the Runner it will wrap has been published yet. The entire toolkit, CLI and Validator and Runner alike, is pre-1.0 and in heavy development.

What will UseArazzo CLI do?

Two commands: validate checks an Arazzo document against the specification, and run executes a workflow against live APIs and prints the step-by-step trace. Both wrap existing libraries, not new logic.

Will it be free?

Yes. Like the rest of the toolkit, UseArazzo CLI will be free, open-source, and licensed under Apache 2.0.

How can I find out when it ships?

Watch or follow the arazzo-toolkit repository, or join GitHub Discussions.
